**Inteligência Artificial + stack tecnológico food service China.** Trazer o que a China opera em produção há anos e que Ocidente ainda está estudando: **IA de decisão (4Paradigm) · food-tech operacional (Meituan/KeeTa) · dark kitchens tech-first · POS integrado · drone delivery**. Não é "importar software", é entender + adaptar + adaptar regulatoriamente pra BR.

## O que entra neste pilar

- **IA de decisão empresarial** · pricing dinâmico · previsão demanda · staffing · fraud detection · churn prediction (4Paradigm é a referência global)
- **Stack food-tech operacional** · plataforma marketplace + delivery + salão + cozinha integrados nativamente (Meituan é o benchmark absoluto)

- **Consultoria de curadoria** · fee por hora ou projeto · empresa BR paga pra que Matheus + Thiago identifiquem stack chinês certo para caso específico
- **Fee de intermediação** · comissão sobre POC (POC · pilot · production)
- **Adaptação regulatória** · fee sobre certificação BR (ANVISA · INMETRO conforme aplicável) via parceria escritório especializado
- **Integração + deployment + suporte** · fee de deploy + acompanhamento inicial
- **Report / consultoria estratégica** · para C-level empresa BR entender playbook Meituan/KeeTa (esse virou hot commodity pós-invasão Brasil)

## Blockers técnicos conhecidos

- **Suporte técnico in-country** · fabricante chinês raramente tem suporte BR estruturado · mediação essencial
- **Documentação em mandarim** · precisa tradução técnica (não Google Translate)
- **Certificação BR** · POS + hardware eletroeletrônico com plug 220V/60Hz + normas ANVISA/INMETRO · custo real
- **Pós-venda + peças reposição** · logística cross-border longa · precisa estoque estratégico
- **Diferença de escala** · sistema desenhado pra loja 1000 pedidos/dia pode ser overkill pra loja BR 200 · adaptação de features
- **Firewall China** · versão internacional dos apps (Meituan · Ele.me) mostra pouca informação · precisa acesso in-country ou via VPN
