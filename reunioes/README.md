## Como registrar uma reunião nova

1. Nome do arquivo: `YYYY-MM-DD-{tema-curto}.md` (ex: `2026-08-15-abrasel-rj-aprovacao.md`)
2. Estrutura mínima:
   - **Data + duração + presentes**
   - **Contexto** (por que essa reunião · o que veio antes)
   - **Pauta / temas cobertos**
   - **Decisões tomadas** (o que ficou decidido · quem é owner)
   - **Ações next steps** (com owner + prazo)
   - **Blockers levantados**
   - **Link pro transcript original** se houver (Plaud · session brain)
3. Tom: assíncrono · leitor não presente entende em 2min · verbos ativos · dados absolutos
